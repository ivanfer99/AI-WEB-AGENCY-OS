# Plugins Aprobados WordPress

## Objetivo

Definir la lista oficial de plugins permitidos para proyectos WordPress de la agencia.

---

# Regla Principal

Usar la menor cantidad posible de plugins.

Cada plugin debe justificar:

- Función clara
- Rendimiento aceptable
- Buen soporte
- Compatibilidad
- Seguridad

---

# Constructor Visual

## Oficial

- Elementor Pro

---

# Plugins No Recomendados

Evitar:

- Plugins abandonados
- Plugins nulled
- Plugins con demasiadas funciones innecesarias
- Múltiples constructores visuales
- Múltiples plugins SEO
- Múltiples plugins de caché

---

# Regla de Aprobación

Antes de instalar un plugin nuevo, evaluar:

- ¿Se puede resolver con PHP?
- ¿Se puede resolver con Elementor?
- ¿Se puede resolver con JetEngine?
- ¿Afecta rendimiento?
- ¿Tiene soporte activo?
- ¿Es necesario para el cliente?
