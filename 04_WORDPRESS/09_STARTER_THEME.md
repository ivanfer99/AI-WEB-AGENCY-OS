# Starter Theme Oficial

## Nombre

Codebreak Starter Theme

---

# Objetivo

Tener una base estándar para todos los proyectos WordPress de la agencia.

---

# Filosofía

El tema no diseña.

Elementor diseña.

El tema proporciona:

- Rendimiento
- Compatibilidad
- Seguridad

---

# Requisitos

- PHP 8.2+
- WordPress actual
- Elementor Pro
- Rank Math
- Fluent Forms

---

# Estructura

codebreak-starter/

assets/
css/
js/

inc/

templates/

woocommerce/

functions.php

style.css

---

# Funciones Base

- Menús
- Logo
- Soporte WooCommerce
- Soporte Elementor
- SVG
- Optimizaciones

---

# No Incluir

- Page Builders
- Shortcodes innecesarios
- Funciones de negocio

---

# Objetivos

Mobile First

SEO Friendly

WooCommerce Ready

Core Web Vitals Friendly

---

# Compatibilidad

- Elementor
- JetEngine
- WooCommerce
- Rank Math
