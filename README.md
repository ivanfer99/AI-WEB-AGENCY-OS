# IA Web Agency OS

Sistema profesional de trabajo con Inteligencia Artificial para creación de proyectos web, SEO, Ads, WordPress, Elementor, WooCommerce y desarrollo PHP personalizado.

## Objetivo

Crear un sistema operativo de agencia web basado en IA para transformar una idea de cliente en un proyecto web completo, documentado, versionado y escalable.

## Stack Principal

- Visual Studio Code
- GitHub
- ChatGPT
- Claude Code
- Codex
- WordPress
- Elementor
- WooCommerce
- PHP
- SEO
- Google Ads
- Meta Ads
- Mermaid
- Stitch / Figma
