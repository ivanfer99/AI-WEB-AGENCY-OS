# Stack WooCommerce

## Objetivo

Definir el stack oficial para proyectos ecommerce desarrollados con WordPress y WooCommerce.

---

# Plataforma Principal

- WordPress
- WooCommerce
- Elementor Pro
- Crocoblock / JetWooBuilder

---

# Uso Recomendado

WooCommerce se usará para:

- Tiendas online
- Catálogos con compra
- Catálogos con cotización
- Productos físicos
- Productos digitales
- Productos variables
- Packs
- Cupones
- Reservas si aplica

---

# Constructor Visual

## Oficial

- Elementor Pro

## WooCommerce Builder

- JetWooBuilder

---

# Reglas Técnicas

- No modificar archivos core de WooCommerce.
- No editar plantillas del plugin directamente.
- Usar child theme o plugin propio.
- Usar hooks y filtros.
- Documentar toda personalización.
- Probar checkout antes de producción.

---

# Reglas Comerciales

Todo ecommerce debe definir:

- Moneda
- Métodos de pago
- Métodos de envío
- Políticas
- Impuestos
- Stock
- Correos
- Cupones
- Condiciones de compra

---

# SEO Ecommerce

Priorizar:

- Categorías
- Productos
- Descripciones únicas
- Schema Product
- Breadcrumbs
- URLs limpias
- Imágenes optimizadas
