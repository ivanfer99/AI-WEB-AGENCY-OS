### Oportunidad SEO del proyecto

Mayhil Express opera en un segmento **B2B con alta intención comercial y competencia moderada**. Las keywords de Transporte de Personal en Lima tienen búsquedas reales con intención de compra, pero pocos competidores tienen sitios bien optimizados.

La mayor oportunidad es doble:
1. **Keywords B2B principales** (`transporte de personal lima`, `empresa de transporte de personal`) — competencia moderada, alta conversión.
2. **Keywords regionales** (`transporte de personal Lima Ica`, `van Lima Ica empresas`) — competencia muy baja, diferenciador único de Mayhil Express.

### Riesgos SEO detectados

| Riesgo | Impacto | Mitigación |
|--------|---------|------------|
| Dominio nuevo sin autoridad | Alto | Empezar a construir desde el lanzamiento con contenido y GBP |
| Keywords B2B compiten con competidores con más antigüedad | Medio | Apuntar primero a long tail y keywords regionales |
| Sitio bilingüe puede generar duplicación | Medio | Implementar hreflang + canonicals correctamente |
| Falta de reseñas en Google | Medio | Campaña de reseñas post-lanzamiento |
| Contenido de servicios sin profundidad | Medio | Página de Transporte de Personal debe ser la más extensa del sitio |

## 11. SEO Técnico

### Checklist técnico para el lanzamiento

#### Indexación y rastreo

| Elemento | Configuración |
|----------|--------------|
| `robots.txt` | Permitir todo el sitio; bloquear `/wp-admin/`, `/wp-includes/`, `/wp-json/` |
| Sitemap XML | Generado automáticamente por Rank Math; enviar a Search Console |
| Canonicals | Configurar en WPML/Polylang para evitar duplicación ES/EN |
| `hreflang` | ES → EN bidireccional en todas las páginas equivalentes |
| Indexación de páginas innecesarias | Bloquear: páginas de login, política de privacidad (opcional), páginas de sistema |
| Paginación | No aplica en Fase 1 (sin blog) |

#### Core Web Vitals

| Métrica | Objetivo | Cómo lograrlo |
|---------|----------|--------------|
| LCP (Largest Contentful Paint) | < 2.5s | Imágenes en WebP, lazy load, Cloudflare CDN |
| FID / INP (Interaction to Next Paint) | < 200ms | Minimizar JS de terceros, LiteSpeed Cache |
| CLS (Cumulative Layout Shift) | < 0.1 | Definir dimensiones fijas en todas las imágenes |
| TTFB (Time to First Byte) | < 600ms | Hosting de calidad + Cloudflare |

#### Open Graph y Social

| Elemento | Detalle |
|----------|---------|
| OG Title | Igual al meta title por página |
| OG Description | Igual al meta description |
| OG Image | Foto del H350 — dimensiones: 1200×630px · formato JPG o PNG |
| Twitter Card | `summary_large_image` |
| Rank Math | Configurar OG por página en la ficha de cada post/página |

#### HTTPS y seguridad

- SSL activo (HTTPS) — verificar redirección automática de HTTP → HTTPS
- Cloudflare: activar HTTPS Everywhere
- No mezclar contenido HTTP dentro de páginas HTTPS (mixed content)

#### Redirecciones

| Caso | Acción |
|------|--------|
| `mayhilexpress.com` → `www.mayhilexpress.com` (o viceversa) | Definir versión canónica y redirigir la otra |
| URLs antiguas del sitio v1 (si existen) | Mapear y crear 301 hacia las nuevas URLs de este PRD |
| Páginas sin contenido o en construcción | 301 a Home — no dejar 404 |

#### Velocidad de carga

| Plugin / Herramienta | Rol |
|---------------------|-----|
| LiteSpeed Cache | Caché de página + minificación CSS/JS |
| Cloudflare Free | CDN + compresión Brotli |
| Rank Math | Lazy load de imágenes integrado |
| Convertir imágenes | WebP obligatorio; herramienta: Imagify o ShortPixel |
| Elementor | Desactivar fuentes de Google si se usan fuentes del sistema |
