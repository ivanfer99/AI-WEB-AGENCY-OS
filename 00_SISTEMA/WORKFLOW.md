# Workflow Profesional

## Flujo general

Cliente
→ Brief
→ PRD
→ Arquitectura
→ SEO
→ Wireframes
→ Diseño
→ Desarrollo
→ QA
→ Lanzamiento
→ Mantenimiento

## Fase 1: Brief

Se recopila información del cliente:

- Negocio
- Servicios
- Productos
- Público objetivo
- Competidores
- Objetivos
- Presupuesto
- Plazos

## Fase 2: PRD

Se crea el documento principal del proyecto:

- Alcance
- Funcionalidades
- Entregables
- Riesgos
- Cronograma
- Criterios de aceptación

## Fase 3: Arquitectura

Se define:

- Mapa del sitio
- Flujo del usuario
- Estructura técnica
- Stack
- Mermaid

## Fase 4: SEO

Se define:

- Keywords
- URLs
- Titles
- Descriptions
- Encabezados
- Contenido base

## Fase 5: Wireframes

Se define la estructura visual de cada página.

## Fase 6: Desarrollo

Se construye el proyecto en:

- WordPress
- Elementor
- WooCommerce
- PHP personalizado

## Fase 7: QA

Se valida:

- Responsive
- Velocidad
- SEO
- Formularios
- Enlaces
- Checkout
- Seguridad

## Fase 8: Lanzamiento

Se publica el proyecto.

## Fase 9: Mantenimiento

Se monitorea y mejora continuamente.
