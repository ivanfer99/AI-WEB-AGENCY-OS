# Cómo Usar el Sistema

## Objetivo

Este sistema permite diseñar, planificar y construir proyectos web profesionales utilizando IA.

No es una agencia comercial.

Es un sistema de arquitectura, diseño y desarrollo web.

# Regla Principal

Antes de crear algo nuevo:

¿Ya existe una plantilla, blueprint o framework que lo resuelva?

Si existe, reutilizarlo.

Si no existe, documentarlo y agregarlo al sistema.
