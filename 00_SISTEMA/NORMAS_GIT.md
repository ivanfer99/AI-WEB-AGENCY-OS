# Normas Git

## Ramas principales

- main: versión estable
- develop: versión de trabajo
- feature/nombre: nueva funcionalidad
- fix/nombre: corrección
- docs/nombre: documentación

## Formato de commits

Usar Conventional Commits:

```bash
feat: agregar nueva funcionalidad
fix: corregir error
docs: actualizar documentación
chore: tarea interna
style: cambio visual
refactor: mejorar código sin cambiar función
seo: actualizar contenido SEO
ads: agregar estructura de campañas
