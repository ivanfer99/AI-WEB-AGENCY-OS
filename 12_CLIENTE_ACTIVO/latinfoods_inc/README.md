# Plantilla de Cliente Activo

Esta carpeta es la estructura base para ejecutar un proyecto web real dentro del sistema IA Web Agency OS.

## Objetivo

Mantener cada proyecto de cliente organizado, documentado y versionado desde el brief hasta el mantenimiento.

---

## Estructura

```text
01_BRIEF/
Información inicial del cliente.

02_PRD/
Documento de requisitos del proyecto.

03_ARQUITECTURA/
Sitemap, Mermaid y estructura técnica.

04_SEO/
Keyword research, arquitectura SEO y metadatos.

05_WIREFRAMES/
Wireframes y estructura visual.

06_COPY/
Textos comerciales y contenido web.

07_DESARROLLO/
Notas técnicas, WordPress, PHP, Elementor y WooCommerce.

08_QA/
Checklist de pruebas antes del lanzamiento.

09_LANZAMIENTO/
Checklist final de publicación.

10_MANTENIMIENTO/
Plan de soporte, backups, actualizaciones y monitoreo.
